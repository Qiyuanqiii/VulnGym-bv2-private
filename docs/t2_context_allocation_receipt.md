现在只改变**取上下文的顺序**：按已声明文件和两种候选角色交替分配；每个文件内沿用已有绑定线索、到关键锚点的距离作检索优先级。它们都不是语义结论，不能直接决定输出答案。

- 所有候选ID、候选本身、公告和diff均不变；没有添加逐题答案、外部路径或隐藏资料。
- 上限仍为16,000字符、12个窗口、8个已声明文件，单窗口3,000字符。
- 锚点逐行对应和遗漏标记仍在，`call_relationship_verified`及`semantic_relationship_verified`仍为false；没有把文本接近当成调用关系证明。
