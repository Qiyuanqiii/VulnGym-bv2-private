## 无凭证核验

解压到获准目录，安装Python 3.10或更新版，在解压目录运行：

```text
python -I -B verify_bundle.py
```

脚本只用标准库，不联网、不调用模型、不执行目标代码、不写输出文件。
它核验文件清单、字节摘要、12条/108项评价、最新候选绑定及保守状态；不证明语义判断正确、评审独立或源码重新回读。
`MANIFEST.json`覆盖除自身外的所有文件；它不是数字签名。通过另一个可信渠道比对发送方给出的ZIP SHA-256，才能核对收到的是同一个包。

有原运行目录和项目源码者，可按演示文档执行真实`verify-handoff`；没有原目录者不能宣称已重放模型或重新验证来源。
部分历史说明链接指向未包含的仓库文件；这些历史附件应从获准的私人仓库获取，不能把缺附件当成已完成证据。
